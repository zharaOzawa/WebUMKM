Landing page responsif yang dibuat untuk memperkenalkan potensi Desa Wisata Panggungharjo, mulai dari produk UMKM, kegiatan desa, hingga informasi kontak.

- Responsive Design
- Modern Landing Page

- Produk UMKM
- Filter Kategori Produk

- Peta Lokasi
- Testimoni Pengunjung
- Form Kontak
- Smooth Scroll Navigation
