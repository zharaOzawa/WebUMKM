# 🌿 Desa Wisata Panggungharjo

Landing page responsif yang dibuat untuk memperkenalkan potensi Desa Wisata Panggungharjo, mulai dari produk UMKM, kegiatan desa, hingga informasi kontak.

## 🚀 Features

- Responsive Design
- Modern Landing Page
- Hero Section
- Produk UMKM
- Filter Kategori Produk
- Timeline Kegiatan
- Peta Lokasi
- Testimoni Pengunjung
- Form Kontak
- Smooth Scroll Navigation

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
